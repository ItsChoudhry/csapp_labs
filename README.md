# Labs for Computer Systems: A Programmer's Perspective

- [ ] **Data Lab**  
       (Chapter 2: Representing and Manipulating Information)  
       Bit-level manipulation in C.

- [ ] **Bomb Lab**  
       (Chapter 3: Machine-Level Representation of Programs)  
       Defuse a binary bomb using assembly and debugging.

- [ ] **Attack Lab**  
       (Chapter 3: Machine-Level Representation of Programs)  
       Buffer overflow and ROP attacks (64-bit).

- [ ] **Architecture Lab**  
       (Chapter 4: Processor Architecture)  
       Optimize Y86-64 code and pipelined processor.

- [ ] **Cache Lab** _(or Performance Lab)_  
       (Chapter 6: The Memory Hierarchy; sometimes Chapter 5: Optimizing Program Performance)  
       Cache simulator and matrix transpose optimization.  
       _Note: Cache Lab is used at CMU instead of Performance Lab._

- [ ] **Performance Lab** _(alternative to Cache Lab in some courses)_  
       (Chapter 5: Optimizing Program Performance / Chapter 6)  
       Optimize kernels for cache performance.

- [ ] **Shell Lab**  
       (Chapter 8: Exceptional Control Flow)  
       Implement a simple Unix shell with job control.

- [ ] **Malloc Lab**  
       (Chapter 9: Virtual Memory)  
       Implement dynamic memory allocator (malloc/free/realloc).

- [ ] **Proxy Lab**  
       (Chapters 11: Network Programming + 12: Concurrent Programming)  
       Build a concurrent caching web proxy.
